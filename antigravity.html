Crash Isolation

Each node's <script> executes inside a sandboxed ErrorBoundary. A thrown exception replaces that node's content with a structured fallback — the physics loop and all other nodes survive uninterrupted.

Node 06 demonstrates this with a deliberate crash.

Rigid Body Properties

  • pos — Vec2 center position (px)
  • vel — Vec2 velocity (px/s)
  • angle — visual rotation (rad)
  • mass — derived from node area
  • restitution — bounciness (0–1)
  • isFixed — true while focused
